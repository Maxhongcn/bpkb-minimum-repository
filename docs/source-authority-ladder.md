# Source Authority Ladder

## S 級
全球頂級策略 / 管理顧問 / 研究機構 / 經典管理來源。  
例如 McKinsey、BCG、Bain、Deloitte、PwC、Gartner、Forrester、Harvard Business Review、MIT Sloan Management Review。  
**用途：**戰略框架、經營模型、組織方法、產業趨勢。

## A 級
成熟 SaaS / CRM / ERP / Automation 官方文件。  
例如 Salesforce、HubSpot、Pipedrive、Zendesk、Intercom、Zapier、Make、Airtable、Notion、Monday、Asana。  
**用途：**流程、欄位、workflow、dashboard、產品化實踐。

## B 級
垂直產業平台 / 類別龍頭 / 成熟案例。  
例如 Shopify、Stripe、Toast、Mindbody、Coursera、Klaviyo、Shopline、91APP。  
**用途：**產業流程、商業模式、垂直場景。

## C 級
Open source / template marketplace / community workflow。  
例如 GitHub、n8n templates、Airtable templates、Notion templates、Miro templates。  
**用途：**可實作流程、automation pattern、樣板。

## D 級
專業部落格 / 顧問文章 / playbook。  
例如 Sales Hacker、Gong、Close、Demand Curve、Reforge。  
**用途：**補充戰術、話術、實務經驗。

## E 級
個人觀點 / 未驗證文章 / AI 推演。  
**用途：**只能作為 hypothesis，不可標成正式 Best Practice。
